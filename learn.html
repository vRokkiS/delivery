Привет

Ты находишься в разделе с полезной информацией для сайта автоматического создания и заполнения документов для реализации доставок. Прежде познакомимся с подсказками, я использовал их что бы разгрузить текст и добавить интерактива. Нажми на меня что бы ознакомиться с ними.

Безопасность

Я сам любитель покопаться в чужом коде в поиске возможностей использовать информацию так, как это изначально не рассчитано. Вся доступная на сервисе информация чистая и не может принести никакого вреда, поэтому мне совсем не страшно, что наш рабочий ресурс находится в открытом доступе

Скорость и удобство

Коллеги участвовавшие в тестировании сервиса отмечают очевидный факт - использовать такой метод создания заявок быстро и удобно. Вам больше не нужно выбирать время доставки из ста вариантов, помнить адреса и номера телефонов магазинов, а для создания акта ТМЦ требуется только номер заявки и номер чека

Безупречность

Я рекомендую всегда проверять данные, которые вводятся при автоматическом заполнении заявки в IntraService, только лишь затем, что бы не остаться крайним. Однако за все время использования не было допущено ни одной ошибки, которая помешала бы организовать доставку

Все поля сайта подвязаны к соответствующим формам на сайте IntraService, важно это или нет, но я подсвечу соответствие каждого поля сайта с полями IS

Товары к доставке

Добавить товар к доставке можно 3 способами (нюанс):

1. Провалившись в проведённый чек ККМ можно скопировать строку товара, таким образом автоматически заполняется Артикул, Наименование, Кол-во, Цена.

2. Провалившись в реализацию, можно скопировать строку с товаром, таким образом автоматически заполняется Наименование, Цена, Кол-во, Цена.

3. Нажав правую кнопку мыши по свободному месту на странице можно добавить строку, где все параметры нужно прописывать вручную: это самый долгий, но надёжный способ добавить товар.

После того, как вы добавили нужное количество товаров (максимум 5, по логике IS) заполните соответствующие поля.

Отправитель и получатель

Без сюрпризов, обратите внимание на то, что данные магазинов вручную на сайте поменять нельзя, при необходимости вы можете поменять их на IntraService. При более серьезных изменениях стоит писать мне обратную связь. Заполнение индекса не обязательно :)

Создать заявку

При нажатии на кнопку вам в буфер обмена копируется код, который нужно вставить на сайт IntraService. Для понимающих - это просто JS код, который нужно вставить в консоль во вкладке отладки страницы. Для простоты использования я в том числе создал расширение для браузера, которое позволяет совершить этот маневр одним нажатием, подробнее об установке этого расширения можно прочитать ниже по тексту

Как установить расширение

Скачайте расширение, разархивируйте его и следуйте следующим инструкциям

Yandex Browser:

  • 1. Вставьте в адресную строку browser://extensions и нажмите Enter
  • 2. Включите «Режим разработчика» в правом верхнем углу
  • 3. Нажмите кнопку «Загрузить распакованное расширение» слева вверху
  • 4. Выберите папку с расширением (внутри должен лежать файл manifest.json)
  • 5. Для удобства закрепите расширение в закладках

Chrome:

  • 1. Вставьте в адресную строку chrome://extensions и нажмите Enter
  • 2. Включите «Режим разработчика» в правом верхнем углу
  • 3. Нажмите кнопку «Загрузить распакованное расширение» слева вверху
  • 4. Выберите папку с расширением (внутри должен лежать файл manifest.json)
  • 5. Для удобства закрепите расширение на панели инструментов (иконка пазла)
